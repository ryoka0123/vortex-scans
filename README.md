# Vortex Scans ⚡

Plataforma moderna, ultra-ligera y optimizada para lectura de Manhwas, Mangas y Manhuas.

## Características

- ⚡ **Zero-bloat:** Sin WordPress ni bases de datos pesadas. Servidor nativo Node.js ultra-rápido.
- 📱 **Lector Webtoon Cascada & Paginado:** Opciones de ajuste de ancho, brillo, modo OLED / Sepia / Zinc, auto-scroll y descarga de capítulos.
- 🔍 **Búsqueda instantánea & Filtros:** Filtro por géneros, tipo (Manhwa, Manga, Manhua), estado y ordenación avanzada (Actualizaciones, Vistas, Calificación, A-Z).
- 🔐 **Sistema de Usuarios & Perfil:** Soporte para Google OAuth, Discord y cuenta local con persistencia de historial de lectura, favoritos y marcadores.
- 🛠️ **Panel de Administración integrado:** Creación y edición de series y capítulos con generador secuencial de imágenes.
- 🛡️ **Preparado para Cloudflare & R2:** Integración lista con almacenamiento Cloudflare R2 sin costo de transferencia (Zero Egress).

## Ejecución Local

```bash
node server.js
```

Abre en tu navegador: `http://localhost:3000`
